# We have not solved the Birch–Swinnerton-Dyer problem yet.

## H26: mixed interposed shears reduce to a finite congruence-subgroup action

Continuation of H25 on the private branch `research/h2-endpoint-20260914`. This checkpoint does not claim a mixed-word obstruction or a BSD solution. It replaces the timed-out word-BFS formulation by the exact algebraic object that must be searched.

### 1. Matrix model

After the first `Phi`, write the two elliptic lifts as a column pair `(P,Q)`. The elementary interposed shears act by

    H(P,Q)=(P-2Q,Q),       H = [[1,-2],[0,1]],
    V(P,Q)=(P,Q-2P),       V = [[1,0],[-2,1]].

Their inverses have the signs of the off-diagonal entries reversed. Hence every mixed interposed word acts by a determinant-one integer matrix congruent to the identity modulo 2.

Conversely, the subgroup generated by these two elementary matrices is the principal level-two congruence subgroup of `SL_2(Z)` up to its central sign convention: in projective action the distinction by `-I` is immaterial for the quartic squareclass calculation. For the finite local search, no presentation theorem is needed: the exact image is obtained simply by closing the two generator matrices modulo the exponent of the local point module.

This matters computationally because a word need no longer be stored. A synchronized state is represented by one matrix residue in each local image; generator application is constant-size matrix multiplication.

### 2. Independent finite image checks

For odd primes 3,5,7,13,17 these sizes equal `|SL_2(F_p)|=p(p^2-1)`, confirming that the mixed shear image is the full determinant-one group modulo each tested odd prime. The powers of two retain the expected level-two restriction.

The calculation is reproduced by `verify.py`, which independently enumerates the same matrix closures and checks determinant one for every state. These checks are structural validation of the new representation, not evidence for a BSD theorem.

### 3. Consequence for synchronized local search

H25's 27,648-state orbit at `p=313` should not be synchronized with auxiliary primes by storing tuples of elliptic coordinates or by choosing one shortest representative per target state. Instead:

1. determine the finite matrix image needed by each local point pair;
2. precompute, for every matrix residue, whether the final `Phi` state is target-compatible, incompatible, or ambiguous;
3. form product congruence images via CRT/strong approximation rather than BFS over words;
4. intersect the accepted subsets in the actual common matrix image.

For pairwise coprime odd moduli, the full odd-prime images found above strongly suggest that the synchronized matrix image factors as the direct product; this must be proved or checked at the exact composite moduli used before treating local acceptance sets as independent. Shared 2-primary factors require separate handling.

### 4. What this does and does not establish

This checkpoint resolves the algorithmic defect identified in H25: the correct mixed-word variable is a congruence-subgroup matrix, not a shortest word. It also explains why naive product BFS became unnecessarily large.

It does **not** yet decide whether some arbitrary mixed word can make the final squareclass exactly 313. The next executable target is to compute the exact matrix modulus for the `p=313` post-Phi pair and one auxiliary prime (starting with 13), label their matrix-image states by the final-Phi condition, and intersect the synchronized image. If that pair survives, add primes one at a time; if it becomes empty, that yields a genuine all-mixed-word obstruction for the audited first-stage class.
